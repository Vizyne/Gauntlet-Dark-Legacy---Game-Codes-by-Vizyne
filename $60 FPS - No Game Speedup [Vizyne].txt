==== 60 FPS - NO GAME SPEEDUP ====
by Vizyne



== WHAT THIS DOES ==
Lets the game run at 60 FPS without speeding up.


== KNOWN ISSUES ==
This code works, but it isn't finished.

1. (Inconsequential) Some camera animations (ex. camera zoom after character(s) load in remain sped up.
2. (Inconsequential) Anti-Death drain effect on Death remains sped up.
3. (Inconsequential) Game has occasional spikes in speed that last for about a second.
4. (Consequential) Basic attack animations are slightly faster than normal when the game is running at 60 FPS.
5. (Consequential) As with the previous 60 FPS code, some ledges become difficult to cross.
	If this happens:
	1) Pause the emulation
	2) Disable the AR & Gecko codes
	3) Resume the emulation and cross the ledge
	4) Re-enable the codes after crossing


== HOW TO USE ==
This is an AR and Gecko code combination. Both codes need to be used together for the game to work properly.

1. Add and enable both codes in Dolphin.
2. In Dolphin settings, set CPU Clock Override to 300% (200% also works, but some more demanding areas in the game will drop to 30 FPS).

Alternatively, if you have the Speed powerup, you can enable it and shove (left trigger) to get over the ledge.
